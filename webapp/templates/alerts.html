Basic rule-based detection

What NetGuard Detects

Port Scan

Multiple network ports are tested within a short period.

Repeated Connection Attempts

Many repeated attempts are made to connect to the same network service.

HTTP Request Flood

An unusually high number of clear-text HTTP requests is observed.

DNS Query Flood

An unusually high number of DNS queries is observed.

Unusual Network Activity

Network traffic rises significantly above its recent normal level.

High Outbound Data Transfer

An unusually large amount of data leaves the monitored device.

Suspicious Port Activity

Traffic uses ports commonly associated with risky or unusual tools.

Basic rule-based detection

NetGuard identifies unusual traffic patterns using predefined rules. An alert is evidence that should be reviewed, not proof that an attack occurred. Legitimate activities such as streaming, downloads, video calls, software updates and cloud synchronisation may sometimes trigger alerts. NetGuard cannot guarantee that every threat will be detected or that every alert is correct.
